# Simulation

Reproducible simulation stack:

- MATLAB/Simulink + Marine Systems Simulator (MSS);
- ROS 2 Jazzy;
- Gazebo Harmonic;
- VRX;
- ArduPilot SITL where the selected controller stack supports it;
- SolidWorks/ANSYS-derived parameters where traceable.

## Required scenarios

- 3 ASVs + optional fourth;
- current direction/magnitude sweep;
- wind/wave disturbance;
- dock and staging area;
- waste/Pontederia mission zones;
- unit loss / LoRa partition / stale task ownership;
- cutter–collector coalition;
- return/service triggers.

Record world/config/seed/vehicle parameters and MCAP outputs. Simulation does not substitute for controlled-water evidence.
