# Simulation

Store reproducible simulation models, launch/configuration files, parameter sets, and result-processing scripts here. Preserve enough information to rerun each result and link significant outputs to EXP/TEST/EVD records.

Current installed project tooling already includes MATLAB/Simulink, ANSYS, ROS 2 Jazzy, Gazebo Harmonic, VRX, and ArduPilot simulation support; use only the tools justified by the engineering question being answered.
